# SentimentIQ

NLP-based Sentiment Analysis and Conversational Assistant.

## Project Overview

SentimentIQ analyzes text and classifies it into:

- Positive
- Neutral
- Negative

The system combines Natural Language Processing, Machine Learning,
and a conversational response engine.

## Tech Stack

- Python
- FastAPI
- Pandas
- NumPy
- Scikit-learn
- NLTK
- spaCy
- Joblib
- React
- TypeScript
- Tailwind CSS
